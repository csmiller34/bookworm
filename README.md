# Bookworm 🐛

A lightweight book search app powered by the [Open Library API](https://openlibrary.org/developers/api).

## Features

- Search by title, author, or ISBN
- Autocomplete suggestions after 3 characters (300ms debounce)
- Shows cover, title, author, first published year, and Open Library rating
- Related books via Open Library subjects
- Clean, minimal UI

## Requirements

```bash
pip install -r requirements.txt
```

## Usage

```bash
python3 app.py
```

Then open [http://localhost:5000](http://localhost:5000) in your browser.
